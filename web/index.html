Cloud Architecture

3-Tier 아키텍처 연동 안내

현재 보고 계신 페이지는 WEB Tier (Apache)에서 서빙되는 고속 정적 진입점입니다.
'PetClinic 시작하기'를 누르면 요청이 내부 로드밸런서를 거쳐 WAS Tier (Tomcat Spring App) 및 DB Tier (MySQL)로 안전하게 연결됩니다.
